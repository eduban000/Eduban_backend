# Eduban Auxiliary Apps

Companion applications that ship alongside the Eduban backend but are not part of
the core API runtime.

| App | Description |
|-----|-------------|
| `portal` | Developer portal with an interactive API playground (Next.js) |
| `content-player` | Reusable learning-content player components (video, audio, quiz, document, and interactive text renderers) with offline support |

These are optional and maintained here for convenience. Each has its own build
setup where applicable.
